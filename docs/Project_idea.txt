Project Title: OmniTracker (Local-First Entertainment Release Tracker)

System Overview : OmniTrack is a zero-database, zero-installation Portable Desktop Application designed to run entirely offline or online from a user-chosen directory (e.g., local folder like drive wwhich wwill be downloaded via github, unzipped and double clicking the application file will redirect to local website and run the website locally. the user profile data will be saved to that folder). Cleaned & Modularized SpecificationsModule 1: Portable App Shell & Direct File System SyncZero-Installation Portable Architecture: Users unzip a single executable (OmniTrack.exe) into any folder or USB drive. Running the executable launches the application UI immediately without writing registry keys or requiring administrator privileges.Direct Local Disk Persistence: User profile data, bookmarks, custom feeds, and reading/watching progress are automatically saved directly to omnitrack_data.json inside the app directory.Native File Operations: Uses native OS file bindings (via Tauri / Rust) so that every bookmark or progress update writes to disk instantly without browser download popups or storage quota limits.Dual Access Modes:Guest Mode: Loads a temporary, non-persisted workspace in memory.Portable Profile Mode: Reads and updates the local omnitrack_data.json state automatically on app launch and shutdown.Module 2: Universal Data Ingestion & API Gateway (FastAPI)Lightweight Serverless Backend Proxy (FastAPI on Vercel): Handles external API key protection and bypasses rate limits.Universal Media Adapter: Converts third-party payloads (TMDB, AniList, MangaDex) into a single TypeScript/Pydantic interface:TypeScriptinterface MediaItem {
  id: string;               // e.g., "tmdb_12345" or "anilist_67890"
  mediaType: 'tv' | 'movie' | 'anime' | 'manhwa';
  title: string;
  coverImage: string;
  latestRelease: string;    // e.g., "Episode 12" or "Chapter 104"
  nextReleaseDate: string;  // ISO 8601 Timestamp
  totalCount: number;
  officialProviders: { name: string; url: string }[];
}
Official Legal API Connectors:TV Shows & Movies: TMDB API (includes legal streaming platform availability via JustWatch).Anime: AniList GraphQL API (airing schedules and episode counts).Manga / Manhwa: MangaDex API / Kitsu API (chapter updates and publisher links like MangaPlus or Viz).Module 3: Custom Source Sync & Feed ParserUser-Defined Web Updates: Allows users to paste custom RSS, Atom, or JSON endpoint URLs to track updates from any arbitrary website.FastAPI Feed Utility: The Python FastAPI backend uses feedparser and httpx to fetch, parse, and normalize custom feeds into the MediaItem format.Module 4: Client-Side Recommendations & Discovery EngineFilterable Media Catalogue: Dropdown interface filtering media by type (TV, Anime, Movies, Manhwa) and genres.Zero-Server Recommendation Logic: Reads bookmarked genres and watch history from omnitrack_data.json on disk, compares them against trending API outputs, and generates recommendations completely on the local computer without sending user profile data anywhere.Recommended Tech StackLayerRecommended TechnologyPrimary PurposePortable ShellTauri (v2)Extremely lightweight (~10MB executable) desktop shell that compiles to a portable .exe and handles disk read/write permissions.Frontend UINext.js / React + TypeScriptBuild the user interface using modern React code.Styling & UI ComponentsTailwind CSS + shadcn/uiClean, dark-mode accessible UI elements.Backend API ProxyFastAPI (Python 3.11+)Hosted on Vercel ($0 tier) to route API requests to TMDB, AniList, and MangaDex.Data Parsinghttpx + feedparser + pydanticAsync Python parsing for RSS feeds and media API payloads.Implementation Roadmap & Step-by-Step PlanPhase 1: Portable Desktop Shell & Local Storage
